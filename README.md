# Bike for Your Life

Bike for Your Life is a terminal typing game about surviving a monster chase on a bicycle. I made it when I was in highschool, and just recently updated the dependancies to work on terminals other than replit.

## Running locally

Use a normal terminal window. The game reads one keypress at a time, so run it in an interactive terminal rather than inside an editor output pane.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

On Windows, activate the virtual environment with:

```bash
.venv\Scripts\activate
```
